What every roadmap contains

The same six parts each time, so you always know where you are and what to do next.

1 / 6

  1. Snapshot

    Your goal, the assumptions made about your level and time, the total duration, and what you’ll be able to do at the end.

  2. The big picture

    Four to six stages in a quick overview, each with a time estimate.

  3. Stage-by-stage plan

    For each stage: the objective, what to learn, specific resources, a hands-on project, a milestone check, and common mistakes.

  4. First 7 days

    A concrete start you can begin today.

  5. Tracking and staying on course

    How to measure progress and what to do when you fall behind.

  6. After the roadmap

    Where to go next: specialties, communities, and ways to use the skill.

Install it

Pick where you use Claude. It takes about a minute.

  1. Download toproadmap.skill from the dist folder of the GitHub repo.
  2. In Claude, open Settings → Capabilities → Skills.
  3. Choose Upload skill and select the file.
  4. Switch it on, then start a chat with something like “I want to learn guitar.”

Skills need code execution and file creation to be enabled, and menu names can change. If you don’t see Skills, check Anthropic’s help center.

Clone the repo straight into your skills folder. This makes it available in every project:

git clone https://github.com/dalil2005/toproadmap ~/.claude/skills/toproadmap

For one project only, clone into .claude/skills/toproadmap inside that project. Restart Claude Code, then ask for a roadmap.

The skill is one file. Copy it into a folder named toproadmap:

mkdir toproadmap curl -o toproadmap/SKILL.md https://raw.githubusercontent.com/dalil2005/toproadmap/main/SKILL.md

Zip the folder if you want to upload it in the Claude app.

Questions

Is it free?

The skill is free and open source under the MIT license. You need a Claude plan that supports skills.

Can I change how roadmaps look?

Yes. Open SKILL.md in any text editor and edit the structure, tone, or rules. It’s plain Markdown.

Are the resources real?

The skill tells Claude to search the web for fast-changing topics and never to invent courses or links.

Where’s the code?

On GitHub: github.com/dalil2005/toproadmap. Stars, issues, and pull requests are welcome.
